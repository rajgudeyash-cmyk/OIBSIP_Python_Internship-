📝 About the Project

As part of my Python Programming Internship at Oasis Infobyte, I developed a simple BMI Calculator using Python and Flask.

The main purpose of this project is to calculate Body Mass Index (BMI) using a person's weight and height. I created this application with a clean and simple interface so that users can easily enter their details and get their BMI result.

This project also helped me understand how Python works with web applications and how Flask handles user input.

✨ Features

- Simple and user-friendly interface.
- Calculates BMI using weight and height.
- Displays the calculated BMI value.
- Shows a BMI category based on the result.
- Handles invalid and empty inputs.
- Responsive design for mobile and desktop screens.
- Attractive gradient background.

🛠️ Technologies Used

Step 5: Open your browser and visit:

📊 How It Works

1. Enter your weight in kilograms.
2. Enter your height in metres.
3. Click on the Calculate BMI button.
4. The application calculates and displays your BMI result.

The application uses the following formula:

BMI = Weight (kg) / Height (m)²
