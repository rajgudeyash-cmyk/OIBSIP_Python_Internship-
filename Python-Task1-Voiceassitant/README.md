Yash Voice Assistant 🎙️

About the Project

This project is a simple voice assistant developed using Python and Flask as part of my Oasis Infobyte Python Programming Internship.

I created this project to understand how voice assistants work and how Python can be used to build interactive applications. The assistant can recognize voice commands through the browser, process them using Python, and respond with a spoken reply.

It also provides an option to type commands instead of speaking.

Features

- Voice command recognition.
- Spoken responses using browser speech synthesis.
- Text-based command input.
- Displays the current time and date.
- Responds to greetings and basic questions.
- Simple and user-friendly interface.
- Responsive design for mobile and desktop devices.

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Web Speech API

Available Commands

The assistant can respond to commands such as:

- Hello
- What is your name?
- What is the time?
- What is today's date?
- How are you?
- Thank you
- Help
- Bye

How to Run the Project

1. Install Python on your device.

2. Install Flask using:
   
   "pip install flask"

3. Download or clone this repository.

4. Open the project folder.

5. Run the Python file:
   
   "python app.py"

6. Open your browser and visit:
   
   "http://127.0.0.1:5000"

7. Click the microphone button and start speaking.
