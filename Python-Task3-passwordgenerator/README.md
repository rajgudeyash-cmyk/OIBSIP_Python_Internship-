📝 About the Project

As part of my Python Programming Internship at Oasis Infobyte, I developed a Password Generator using Python and Flask.

The purpose of this project is to generate random passwords based on the length selected by the user. The application allows users to generate passwords between 8 and 64 characters.

I used Python's built-in "secrets" module to generate random passwords, making the application more suitable for creating unpredictable passwords.

The application has a simple and attractive interface that works on both mobile phones and desktop screens.

✨ Features

- Generates random passwords instantly.
- Allows password lengths between 8 and 64 characters.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Uses Python's "secrets" module for secure random selection.
- Simple and user-friendly interface.
- Responsive design for mobile and desktop.
- Handles invalid password lengths and inputs.

🛠️ Technologies Used

⚙️ How It Works

1. Open the Password Generator application.
2. Enter your desired password length.
3. Choose a length between 8 and 64 characters.
4. Click on the Generate Password button.
5. Your randomly generated password will appear on the screen.

The application uses Python's "secrets.choice()" function to select random characters from letters, numbers, and special characters.
